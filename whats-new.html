What's new

Velocity gets better all the time. Here's what changed, and what's coming next.

Coming next Roadmap

  • Digitally signed installer, so Windows recognises Zemaris as the publisher
  • Velocity in the Chrome Web Store, for one-click browser setup
  • macOS and Linux releases, then Android (including Huawei AppGallery), then iPhone & iPad

Velocity 1.7 Current

October 2026
  • Live progress window for each download: connection map, speed chart, average and top speed, connection table, its own speed limit, and open / show in folder / sleep / shut down when finished
  • 89 languages, all built in, with right-to-left layout for Arabic, Urdu, Persian, Hebrew, Pashto and more
  • Same-name files: save with a new name, replace, or skip
  • Virus scan of finished downloads with Microsoft Defender (optional)
  • Finish sound when a download completes
  • Ready for macOS and Linux (now in testing)
  • Fixed garbled symbols in the Download File Info window

Velocity 1.6

October 2026
  • 30-day free trial with every feature, and a countdown in the toolbar
  • Licence keys for Monthly, Yearly, Lifetime and Business plans, checked offline on your PC
  • Help → Licence window to activate, see your plan, or move your key to a new PC
  • When a plan ends, unfinished downloads wait safely and carry on as soon as you activate

Velocity 1.5

October 2026
  • Torrents: magnet links and .torrent files, with the same controls as every other download
  • Playlists and channels in one click, each saved in its own folder
  • Subtitles downloaded and built into videos
  • Self-updating video engine, checked against its fingerprint before use
  • Clipboard monitor and site grabber for every link on a page
  • Books folder for EPUB, MOBI, AZW and more
  • Image download button (optional) for full-size pictures
  • Urdu, Arabic and Hindi, with a short welcome tour
  • Faster engine that reuses connections between parts

Earlier versions
