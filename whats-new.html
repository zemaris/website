What's new

Velocity Download Manager gets better all the time. Here's what changed, and what's coming next.

Coming next Roadmap

Planned
  • Digitally signed installer, so Windows names the publisher instead of "Unknown publisher"
  • Velocity in the Chrome Web Store, for one-click browser setup
  • macOS and Linux releases (now in testing)
  • Zemaris PDF, our PDF editor, in the Microsoft Store as well as on zemaris.com
  • Later: Android (including Huawei AppGallery), then iPhone & iPad

Velocity Download Manager 1.7.9 Current

November 2026
  • Setup tells you it is updating: when Velocity is already installed, Setup says it will update it and keep your downloads, settings and licence
  • When you change your plan, Velocity picks up the new licence key by itself
  • Small reliability fixes

Velocity Download Manager 1.7.8

November 2026
  • HD video and MP3 work straight away: if your PC has no FFmpeg, Velocity gets it by itself the first time it is needed, one time only, and carries on with the download
  • The file is checked against its fingerprint before it is used, and an FFmpeg already on your PC is always used first
  • Clearer messages if FFmpeg can't be downloaded or set up

Velocity Download Manager 1.7.7

November 2026
  • YouTube downloads are more reliable: if a video's formats don't arrive the first time, Velocity asks once more before giving up
  • FFmpeg is found on its own, even when it was installed after Velocity started, and Velocity says plainly when a video needs it
  • Clearer messages when a video can't be downloaded, in all 88 languages
  • Faster video info for links from a playlist or Mix
  • Newer video engine

Velocity Download Manager 1.7.6

November 2026
  • Its own link: the browser extension now starts Velocity with a link only Velocity uses, so another program can't take it over
  • Updates window in every language: its texts and messages are translated into all 88 languages
  • Your licence key is confirmed about once a day and when you open the Licence window, so a renewed or changed plan reaches you sooner
  • Safer trial and key checks, and a licence file that another program has open is never overwritten
  • Removing a key from a PC is limited to 3 times in 30 days; past that, the key stays and Velocity tells you to write to admin@zemaris.com

Velocity Download Manager 1.7.5

November 2026
  • A new name: Velocity is now called Velocity Download Manager, by Zemaris
  • Nothing else changes for you: your downloads, settings and licence key stay just as they are, and the update installs like any other

Velocity 1.7.4 First public release

November 2026
  • Download File Info window: Cancel, Esc or the X really closes it, so the same link opens a fresh window next time, and a different quality gets its own window
  • Downloads from server farms and mirrors keep their progress: when only the server's file tag changes, Velocity compares pieces it already has and starts again only if the file really changed
  • Logins on a site's own sub-domains (such as www.) are kept again, and never passed to another site
  • Safer local connection: only Velocity's own windows can change its settings; anything else can only send downloads, as the browser extension does
  • Every window text is translated again in every language

Velocity 1.7.2

October 2026
  • Licence agreement shown during setup, and open-source notices installed with Velocity
  • FFmpeg is your choice: setup offers it as a tick box instead of installing it quietly
  • Polite updates: setup asks Velocity to close and waits, instead of closing it by force. Velocity saves and quits cleanly when Windows signs out
  • Safer updates: each new version is checked against its size and SHA-256 fingerprint, over a secure connection only, before it is installed
  • Updates window shows progress and explains in plain words if an update was refused
  • Subscriptions renew by themselves: Velocity picks up the renewed key, so there's nothing to paste
  • On macOS and Linux, Velocity tells you when a new version is out
  • Smaller installer (about 21 MB)

Velocity 1.7.1

October 2026
  • Licence keys tied to your PCs, so a key works on the number of PCs in your plan
  • Ready for our activation server, so a refunded or leaked key can be switched off

Velocity 1.7

October 2026
  • Live progress window for each download: connection map, speed chart, average and top speed, connection table, its own speed limit, and open / show in folder / sleep / shut down when finished
  • 89 languages, all built in, with right-to-left layout for Arabic, Urdu, Persian, Hebrew, Pashto and more
  • Same-name files: save with a new name, replace, or skip
  • Virus scan of finished downloads with Microsoft Defender (optional)
  • Finish sound when a download completes
  • Ready for macOS and Linux (now in testing)
  • Fixed garbled symbols in the Download File Info window
