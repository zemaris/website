Velocity PDF

Velocity PDF is not released yet. Its full notices file will be published here and installed with it. It is built with these open-source parts, among others:

  • PDF.js (shows PDF pages), Apache License 2.0
  • pdf-lib and fontkit (write PDF files and fonts), MIT License
  • Tesseract and Tesseract.js (text recognition), Apache License 2.0
  • whisper.cpp (voice typing, downloaded only if you use it), MIT License
  • Liberation fonts, SIL Open Font License 1.1, and the standard PDF fonts that come with PDF.js, under their own permissive licence

Velocity PDF also uses Microsoft Edge WebView2, which is part of Windows and covered by Microsoft's own terms.

Questions, or a request for source code under a licence that offers it: admin@zemaris.com.
